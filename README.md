ReparaRed

Plataforma que organiza la búsqueda de reparaciones domésticas, conectando a quien necesita un servicio con técnicos independientes.

El problema actual: encontrar un técnico de confianza, conocer precios previos y comparar opciones suele ser informal y disperso, basándose en recomendaciones personales o llamadas sin estructura.

La propuesta: una web donde los clientes publican la reparación (con fotos y detalles) y los técnicos envían cotizaciones. El cliente elige, se coordina el servicio y se mantiene el seguimiento hasta la finalización.

Para el cliente: publicar una necesidad y recibir diferentes propuestas desde un solo lugar.
Para el técnico: encontrar oportunidades relacionadas con su especialidad y presentar cotizaciones para construir su reputación.

Áreas iniciales: gasfitería, electricidad básica, reparación de muebles y limpieza especializada.

Estado: MVP de proyecto final de curso.
